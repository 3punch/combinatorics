# تَرکیب — آزمایشگاه تعاملی ترکیبیات

یک محیط فارسی و راست‌به‌چپ برای ساختن گراف، مشاهدهٔ ویژگی‌ها و محک‌زدن حدس‌های ترکیبیاتی. هدف پروژه «کشف کردن» است، نه فقط دیدن پاسخ.

## امکانات نسخهٔ اول

- ویرایشگر تعاملی گراف: افزودن/حذف رأس و یال، جابه‌جایی رأس‌ها و بزرگ‌نمایی
- واگرد و ازنو، نمایش درجه‌ها و ذخیرهٔ گراف در مرورگر
- تحلیل زندهٔ همبندی، مؤلفه‌ها، درخت، دور، دوبخشی، عدد رنگی و مسیر/دور اویلری
- حدس‌ساز برای بررسی گراف فعلی و بارگذاری مثال نقض
- چالش تعاملی Ramsey و رنگ‌آمیزی یال‌های K₆
- مسیر یادگیری با مثال‌های آماده و دفتر یادداشت محلی
- کتابخانهٔ جزوهٔ «مبانی ترکیبیات» دکتر امیر مافی با PDF کامل ۲۴۶ صفحه‌ای
- فهرست تعاملی ۷ فصل و ۴۲ بخش، جست‌وجو، مطالعه از صفحهٔ متناظر و ثبت پیشرفت
- اتصال فصل‌های گراف به آزمایشگاه و امکان دانلود منبع
- رابط واکنش‌گرا برای موبایل و دسکتاپ

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخهٔ production:

```bash
npm run build
npm run preview
```

## فناوری‌ها

React 19، TypeScript، Vite، SVG و Lucide. محاسبات ریاضی در `src/graph.ts` با الگوریتم‌های قطعی انجام می‌شوند و به سرویس خارجی یا LLM وابسته نیستند.
